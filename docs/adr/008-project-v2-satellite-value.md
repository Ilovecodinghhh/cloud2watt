# ADR-008：项目 2.0 采用诊断驱动的卫星增量价值验证

日期：2026-10-01（Asia/Singapore）。
状态：已采纳为项目 2.0 规划决策；实施、训练与数据扩展未开始。
依据：用户要求结合卫星融合退化的可能原因，提出尽可能完备的解决与验证方案，作为项目 2.0 并用文件记录决策。

## 背景

2026-09-28 精简路线已完成九组 CPU 训练。开发主 MAE：MLP 4.375、power_solar 5.103、full 5.397
个装机容量百分点。full 相对配对纯功率退化约 5.75%，相对强 MLP 退化约 23.35%；
四个开发留出站点上 Smart Persistence 最好。当前证据不能证明卫星普遍无用，也不能证明更大模型一定有效。

当前数据仅为冬季 20 站点、30 天；最多八轮训练、32² 卫星输入、CNN 全局池化后 GRU、固定空间 jitter、
训练目标与日间选模指标不一致，均产生可检验假设。原 test 已曝光，不能用其作为新独立确认。
当前代码已有时序编码、缺帧 mask、训练期标准化与恢复机制，不能把这些能力误写成完全缺失。

## 决策

| ID | 采纳内容 | 理由与后果 |
|---|---|---|
| D01 | 将本次路线命名为“Cloud2Watt 项目 2.0”，另设计划修订号 | 与已有评估 v2.0/v2.1、数据 v2、软件包 0.1.0 区分；不把计划等同发布 |
| D02 | 先诊断、正确性、预算与基线，再试有限卫星改进 | 优先排除数据/优化问题，控制搜索成本；负结果也可完成交付 |
| D03 | 同时对照最强无卫星 B* 与结构配对 P* | 区分真实竞争力、换骨干收益与卫星信息增量；必要时加容量对照 |
| D04 | 先检验同口径曲线、空间 jitter、损失对齐、分辨率和空间位置保留 | 这些都有当前实现依据；不能仅凭训练/验证原始两列差值宣称过拟合 |
| D05 | 残差/门控优先作为有依据的结构候选，改变结构最多两个 | 保护强功率主线，提供缺卫星回退；不保证误差天然单调改善 |
| D06 | 保留标签代理与日间 30/60/120 主指标，预留执行协议 `c2w-eval-v2.2` | 新预算/选择规则必须有新身份；v2.2 尚未实现，旧 v2.1 结果不改名 |
| D07 | 路线 A 保持现有数据；路线 B 为有条件的跨季节/区域确认 | 延续 ADR-007 不自动扩容；扩展前冻结实际日期、站点、成本及新盲测 |
| D08 | 承接三种子、共同样本、日期块 CI、≥5% 实用门和独立时间/区域结论 | 防止相关滑窗、选 seed、重复调参与探索性分组夸大结论 |
| D09 | GPU 是效率工具，先补 CUDA/AMP/恢复验收 | 设备变化可能改变数值与预算，不能把换 GPU 当作精度提升证据 |
| D10 | 所有候选、失败、预算、偏离与停止决定入账 | 不只保存最好结果；超预算不能静默继续，冻结测试后不再优化 |
| D11 | 共同样本精度与完整服务可用性分别验证 | 防止通过排除缺卫星/难天气样本制造收益；延迟接入与回退需实现并验收 |
| D12 | 本轮只落地方案、决策与文档入口 | 用户此次要求规划记录；不启动训练、下载、部署或发布，不覆盖已有成果 |

完整原因矩阵、阶段验收与结论等级见 [项目 2.0 总方案](../PROJECT_V2_PLAN.md)；
运行矩阵、预算、具体配置、失败路径与登记模板见 [实验计划](../PROJECT_V2_EXPERIMENTS.md)。

## 方案取舍

| 备选 | 本轮处理 | 原因 |
|---|---|---|
| 立即换 GPU 或加大模型 | 不作为默认解决方案 | 未隔离优化不足、数据与表示问题；GPU 本身不提供新信息 |
| 只延长 full 训练，与旧八轮 MLP 比较 | 不采纳 | 预算变化与模态变化混杂；需要对称的新基线 |
| 完全放弃卫星 | 暂不作普遍结论 | 数据/预算有限且存在可检验的实现假设；允许本轮负结果后停止 |
| 直接全面扩站点/年份 | 作为条件路线 B | 先验证管道和成本，避免扩大错误；新天气/区域证据仍是最终泛化所需 |
| 遍历所有结构、通道、分辨率、损失组合 | 不采纳 | 小验证集会被反复搜索；最多六个单因素候选且结构最多两个 |
| 在旧 test 上重新证明收益 | 不采纳 | 已曝光的信息无法通过改名或重切分恢复独立性 |
| 自监督、NWP、概率预测、大型模型 | 保留为后续研究 | 增加外部数据与成本，当前先检验确定性卫星增量；需单独证据与预算 |

## 预算与执行边界

路线 A 正式拟合运行数上限 56，路线 B 上限 48，合计最多 104，分阶段通过才执行；这是上限而非必跑清单。
主干、残差头、树模型和交叉拟合子模型按实际拟合计数，必要时缩减候选；不能藏在单一策略名字下漏计。
各阶段同时受小时、存储与候选数量限制，具体拆分以实验计划为准。新数据绝对日期、站点、实际硬件
与成本尚未核查，不能称为已冻结的数据实施单。预算耗尽或候选无改善时接受负结果，不无限追加。

原 c2w-eval-v2.0 的严格评估原则保留，其旧实施顺序与预算在项目 2.0 中由本决策和两份新文件取代；
ADR-007 已完成实验的冻结预算和所有历史报告保持原样。本决策不追溯改变历史运行合法性或排名。
