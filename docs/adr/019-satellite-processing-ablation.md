# ADR 019: 卫星处理对照实验（2026-10-09）

用户授权验证昼夜处理、稳健标准化和更小范围卫星特征。沿用 ADR 017 的三个滚动窗口及其冻结 dataset.npz，不重建或筛除任何评价样本，不读取最终测试标签，不下载，不自动替换 MVP。

预先固定四个新变体：daylight（昼夜处理）、robust（稳健标准化）、local32（中心 32×32 图块）、combined（三者结合）。对照为既有同窗口同种子的 satellite_stats、power_solar 与两种持续性基线；复用旧预测前核对其样本、目标、掩码与数据哈希。

昼夜处理：用每个历史帧时刻的本地太阳高度，固定 gate=clip(elevation/5,0,1)，乘到 VIS006、IR_016 的每个帧统计量，保留 IR_108。之后重算三段帧差。这是特征编码，不宣称反射率物理零，也不是整幅图的逐像素日照校正；不添加维度。

稳健标准化：仅卫星特征用训练集中位数居中、IQR/1.349 缩放；IQR 近零时退回训练标准差，再近零则取1。缩放后固定裁剪到 ±5。功率、太阳、站点特征继续训练集均值/标准差，不裁剪。验证与外部数据均复用各自窗口的训练参数，不能用于定阈值。这是稳健缩放加特征裁剪的组合，不能单独归因为其中一项。

局地图块：在原 128×128 中心固定取 [48:80,48:80]，保留四象限均值、全图标准差与帧差的相同 105 维格式，输入仍为 132 维；不搜索最佳尺寸。

所有新变体使用相同 128/128 MLP、Adam 0.001、batch512、dropout0.1、20轮、种子20261008/9/10，共36次 GPU训练。仅内部验证白天30/60/120分钟MAE选轮次。新输出 outputs/project-v2/satellite-ablation-20261009，单实例、可恢复检查点，总流程6小时保护，D盘资源遵守原预算。

报告春季12天滚动外部结果、各窗口结果及最后窗口模型的冬季6天结果。按整日期配对 bootstrap，三种子误差先平均；对四项新处理相对原卫星的比较同时报告95%和Bonferroni98.75%区间。日期已有开发使用且相邻天气相关，全部作为探索性结果，不代表独立最终测试显著性，不用外部结果继续改参数。
