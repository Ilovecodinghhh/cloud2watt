# ADR 012：现有数据 GPU 轻量训练

日期：2026-10-08。状态：接受。

用户明确授权使用现有功率、卫星图块、本地太阳几何与晴空特征，并使用 Conda GPU 环境训练；必须补充时先登记具体对象。本决策更新 ADR 011 中仅改计划、不自动训练的阶段限制，其他数据与最终标签边界保持有效。

首轮使用已经验收的 76,199 样本保守划分。先通过当前训练器的跨进程恢复检查（随机顺序、dropout、模型与优化器/RNG 恢复），再运行 GPU 功率太阳 MLP 与加入卫星局部统计及帧差的 MLP，辅以 persistence 和 smart persistence。此为轻量统计特征路线，不是完整 CNN 对照，不能据此否定原始图像表征。太阳未来特征仅由时间坐标本地计算，归一化只在 fit 拟合，inner 白天 30/60/120 分钟 MAE 选 checkpoint。

单种子 20261008，各 20 epochs，两个模型各约 3500 秒训练上限；不扩展到多种子。卫星不做空间增强，jitter=0、workers=0；恢复验收仅覆盖此配置，不宣称原 CNN 多 worker 随机增强已验收。QC 边缘使用上一阶段保守排除清单，本轮不恢复边缘样本。

具体试验登记：outputs/project-v2/local-gpu-20261008/preregistration.json；输出同目录。补充对象为空，不启动网络下载。最终测试标签锁定，全部结果为开发证据。
