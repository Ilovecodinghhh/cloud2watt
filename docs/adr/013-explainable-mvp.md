# ADR 013：可解释 MVP 前四步与验收

日期：2026-10-08。状态：接受并实现。

用户授权完成预测方案、卫星价值验证、解释输出和缺测回退，并要求验收。复用 ADR 011/012 的安全划分和本地缓存，不扩大数据下载或读取最终测试标签。

默认采用固定种子 20261008 的功率＋太阳/晴空模型，保留晴空修正持续性基线。卫星统计模型手动开启且始终标记实验性；不按 outer 或春季误差选择部署种子。另训练同种子的功率＋静态站点消融模型用于展示加入太阳特征前后的预测差异。差异包含独立训练和参数量变化，不作因果或严格加性归因。

验证复用首个种子，追加 20261009、20261010。每组 20 epochs，只用 inner 选择最佳轮次。以三种子平均的配对误差差值进行 10,000 次 UTC 日期块 bootstrap，整天保留所有站点及各时效的相关性；报告分种子结果和短日期窗口限制，不把数万个样本视为独立样本。

卫星打乱每种子每角色 20 次，同站点同 UTC 钟点跨日期置换完整卫星特征向量，控制日照周期。只有一个可用日期的格保持不变并记录，不删样本；冬季 16 个，春季 0 个。初版未匹配钟点的对照保留为历史，修订记录在 shuffle-amendment.json。该对照是输入敏感性分析，不报告为正式置换显著性检验。

冬季平均差值 +0.000287、95% 区间 [-0.003368, 0.002984]，跨零且三种子有两个变差，不能支持稳定增益。春季相对功率模型区间为负，但仅五天，且仍弱于晴空持续性基线。因此卫星默认关闭。当前结论限于开发集及三种子；日期间天气自相关、模型容量差异和多重探索均限制统计解释。

MVP 接口只接收预测时刻、站点、历史功率与可选卫星特征，不接收未来标签。太阳/晴空按坐标和时间计算。功率历史缺失、无效或时间不对齐时不可用；卫星缺失、无效或时间不对齐时回退至主模型。输出时间、质量原因、实际模型、checkpoint 哈希、对照预测和非因果说明。

本次不实现第五步网页交互或实时数据接入。交付可调用接口、JSON 请求/响应与解释图。补充对象为空。
