# ADR-011：现有数据优先，暂停全量下载

日期：2026-10-07；状态：已接受。依据用户“重新调整计划，尽可能利用现有数据，或者使用易于补充的数据”。

本决策取代 ADR-009/010 中以 408 分区和全部最终原始文件下载为当前执行目标的条款；研究目标、冻结原始日期/站点、历史产物、账本、资源上限及最终标签门保持有效。原任务未完成，改为延期，不记为成功。

停止经命令行和创建时间确认的下载 PID 47172，保留中断分区及缓存；暂停 cloud2watt-b 并重写提示，禁止恢复旧全量入口。此停止为用户调整范围所需，不是数据错误。新配置单独保存，原 route-b-freeze.json 与 plan.json 不改写。

采用 [现有数据优先计划](../PROJECT_V2_LOCAL_FIRST.md)；机器范围见 configs/project-v2/local-first.json。先质量溯源、边界验收与小预算开发对照，再决定是否有必要补充。当前补充对象为空；新对象需事前登记且限制 256 MiB/30 分钟，不能重置已有重试限额。未经验证的新外部源不列为必需依赖。

不自动训练、不解锁最终标签。现有数据按开发角色使用，独立泛化验证延期；不能将缩小范围后的实验声称为原三季三折协议已完成。
