# ADR-007：保留现有规模的开发验证与演示

日期：2026-09-28。状态：根据用户“按这条路线继续”的授权实施。

## 决策

采用“明确目标 → 修正现有数据 → 公平对照 → 演示”。不扩展月份或站点，不以跨季节泛化
作为本轮交付条件。原 S3–S8 大规模路线保留为将来的可选升级，不自动继续。

目标定为三个五分钟采样功率的均值代理；保留已核对的换算尺度，不再声称该标签来自连续电表积分。
这解决了本轮作品集的表述与目标选择，不等于获得上游对五分钟计量方式的新确认。
主 MAE、日间阈值和时效不变，协议 ID 升为 c2w-eval-v2.1，详细预算见
[冻结方案](../COMPACT_ROUTE_PROTOCOL.md)。

使用新目录 paired-30d-corrected-v2，从缓存中的同一源归档重新裁剪，并直接写共享 tile。
修正投影后全部覆盖区域像素有限，原功率和样本表可保持字节一致；旧数据不改写。
本轮不需要年度源缓存淘汰方案，也不使用 S2 的年度成本推算来授权扩容。

三个学习候选、三个种子、固定八轮上限，外加两个朴素基线。候选排序及展示只使用开发验证，
最终示例固定 seed 42，不选择最漂亮的种子。结论限于此数据、输入分辨率和预算。

## 后续可选升级

如果之后重新要求跨季节/区域证据，再恢复原扩容路线：确认独立标签契约、独立测试、实际区域成本、
有上限的源缓存、真实发布延迟与数据再分发许可。当前离线演示不承担这些声明。
