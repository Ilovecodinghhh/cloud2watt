# ADR 018: 卫星质量排查后的处理边界

用户授权先排查，不自动重训。检查仅限已完成的本地 2021 开发数据；最终标签继续锁定。详细依据见 docs/PROJECT_V2_SATELLITE_QUALITY_AUDIT.md。

当前已定位的缺帧、图内缺失未进入三个滚动窗口的实际模型输入。白天无整帧重复或常数图证据；保守统计尾部标记不能视作坏图。模型在无标记子集仍有退步，不根据该关联作因果归因。

源 metadata 的物理单位不能直接解释当前缩放后的数值；逆变换尚未建立，禁止据此盲目作物理阈值截断。保留所有源文件与旧训练结果。后续若实施增强处理，阈值仅由各窗口自己的训练数据拟合，评价样本与模型对照保持一致，优先区分昼夜、太阳高度与空间尺度影响。
