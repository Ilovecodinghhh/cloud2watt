# ADR-020：补充后续十四天的配对验证数据

日期：2026-10-09。依据：用户明确要求补充所建议的十四天数据直到完成。

范围固定为原30站、2021-04-21至2021-05-05（结束不含），三开发区域，VIS006、IR_016、IR_108。保留原窗口每日期前3小时、后6小时支持；支持数据仅用于历史、目标与QC，不另计验证日期。源对象在plan.json登记，五月功率月文件在pv-plan.json登记后传输。不得因缺测换站或日期。

新产物独立存放route-b-spring-validation-v1。只下载、质量检查、配对和完整性验收；不训练、不运行新日期模型评分、不读取2022最终标签、不恢复旧自动任务。新增日期保留作验证。

冻结当前extended窗口的三种子power_solar、原satellite_stats以及local32模型和归一化文件哈希；后续主对照为local32相对power_solar，原卫星为次要参照，晴空持续性为基线。预留日间30/60/120分钟MAE、同样本配对日期块区间，不据新增结果改模型。本任务不执行评估。

预算沿用缓存4GiB、单响应16MiB、累计源传输100GiB、新持久产物16GiB、磁盘空闲20%。本批卫星传输上限4GiB，全部执行3小时保护。五月保留两次历史尝试，最后一次采用固定revision的8MiB Range分段、检查SHA256；不清空重试或预算账本。卫星每对象最多两次，固定generation并检查CRC32C/SHA256。仅淘汰非本批需要的自有缓存源块，不删除历史产物。

完成需42分区完整哈希与时空对齐验收，源缺测单独列明。达到源端或预算限制时如实报告，不伪称完整覆盖。
