# ADR-021：冻结模型在新增春季日期上的评价

用户授权执行对照评价及分组分析，不重训、不调参、不替换模型。沿用ADR020冻结的extended模型、三个种子、归一化参数与主指标，校验18个文件哈希。

范围2021-04-21至2021-05-05结束不含。复用ADR017组内QC与逐样本原始支持边界检查，所有方法使用相同样本和目标掩码。主指标为未来30/60/120分钟太阳高度大于5度的容量归一化MAE，各时效等权，先平均各随机种子的误差而不是预测。主比较local32减power_solar；原卫星、晴空持续性为参照。

冻结前分析规则：按6个预测时长分别报告；太阳高度分5–20、20–40、40度以上，描述几何日照条件，不当作实测晴天/多云标签。功率波动定义最近4次功率最大相邻绝对变化，分组阈值仅取extended训练集日间样本的三分位点。分组为探索性描述，不据其改模型。

主比较给出10,000次整UTC日期配对bootstrap 95%区间，所有站点和种子保持配对；附连续3天循环移动块bootstrap敏感性分析，处理部分相邻天气相关性。次要比较和分组不声称独立确认性显著。只有14天且已查看旧春季开发日期，不能当作最终跨季节结论。2022最终标签保持锁定。

不下载；使用指定Conda和GPU做推理。输入、预测、指标、QC审计与哈希收据落盘。新增日期在本次评分后成为已查看的开发验证数据。
