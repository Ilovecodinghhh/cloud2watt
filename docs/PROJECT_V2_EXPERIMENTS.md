## 1. 先冻结，再运行

每个阶段运行前，填写本文件第 8 节登记字段，保存不可变配置及源码快照。没有具体日期/站点、
输入与目标契约、配置、资源上限、选择规则的阶段不能进入正式训练。不得使用旧 compact 命令
自动执行本矩阵，或通过修改旧 config、complete.json 和协议字符串把旧运行标成项目 2.0。

“冻结”表示结果产生前保存带 hash 的完整登记；调整方案需新增修订和变更原因，保留旧结果。
失败、取消、OOM 和超时计入尝试账本与实际资源消耗，不因没有最终指标从搜索历史消失。
同一身份中断恢复是一组运行；身份完全一致的已完成筛选可复用为确认 seed，不重复计为独立证据。

新产物建议放在 `outputs/project-v2/<stage>/<run_id>/`。数据新建带 manifest hash 的版本目录，
不覆盖 `paired-30d-corrected-v2` 和 `outputs/compact-route-v21`。
所有 Markdown、代码、配置与日志文本使用 UTF-8 无 BOM；源数据/权重继续不入 Git。

## 2. 默认计算与选择规则

| 项目 | 路线 A 默认值 / 执行约束 |
|---|---|
| 数据 | 当前修正的 20 站点、30 天；原 validation/development 用于筛选，validation/holdout 仅开发诊断 |
| 旧 test | 不评分、不作可视化、不重新用于挑选配置；读取器先限制分区再载入目标 |
| 主指标 | 日间 30/60/120 分钟 MAE 等权平均；目标太阳高度角 >5° |
| 种子 | 筛选 42；确认补 123、2026；三者全部报告 |
| E10 最大训练 | 40 epochs，前 10 轮不早停，之后 patience=8；每轮评分，保存更早的同分 checkpoint |
| E10 优化器 | 保留 compact 的 MLP Adam、融合 AdamW；lr=0.001、weight_decay=0、dropout=0.1，不加 scheduler |
| batch | 有效 batch=128，使用全部训练样本；累积按有效目标数正确归约，记录末组处理 |
| E10 设备 | CPU FP32、threads=2，保留 compact 条件以隔离预算因素；若改用 GPU，另登记为运行条件变化 |
| 后续设备 | 通过 E02 后选择 CPU 或 GPU 并在同一神经网络对照中固定；AMP 单独通过验收才启用 |

| 神经训练上限 | E20/E30 默认沿用 40 epochs、最少 10、patience=8；配置筛选不得偷偷使用不同上限 |
| 树模型上限 | 若启用 boosting：最多 500 轮，固定 learning_rate=0.05、inner 早停 patience=50；树实现与其余配置先冻结；路线 A 用原开发验证作 inner |
| 路线 A 资源保护 | 本地 CPU 运行累计 24 小时、GPU 占用累计 16 小时，含评估/I/O；新增持久产物 10 GiB，上限先到先停 |
| 路线 B 资源保护 | 预估起始上限为本地 GPU 72 小时或 CPU 144 小时、全部新增数据/缓存/产物合计 200 GiB；需在覆盖预检后冻结适用值 |

资源数值是本方案的初始上限，不是耗时承诺，也不表示已消耗或批准付费算力。CPU 小时按单进程墙钟
计，不乘线程数；多进程累加。GPU 按卡时累加，不把 CPU 时间混成 GPU 时间。默认一次一个正式训练任务。
上述限制与运行数/epoch 限制同时生效；若实测无法在限额内完成，先缩减预登记候选或记录新预算决策，
不能只延长落后的卫星模型。无需购买或安装新硬件来完成本次文档交付。

允许复用的条件必须同时满足数据、样本键、mask、标签、统计、源码、依赖、设备/精度、优化配置、
增强、训练预算和选择规则身份一致。8 轮 compact 结果只能作历史参考，不能代替本轮 40 轮对照。
训练不足但达到预算时标记“在上限内尚未收敛”；下一轮如延长，所有被比较策略获得相应机会。

E30 的 23 次上限分解：六个卫星 seed42 + 最多六个新配对 seed42 + 最多两个候选及其配对各补

改变神经网络结构的候选最多两个；其他名额用于增强、分辨率、统计或损失等单因素。
如果配对控制不够，减少候选而不是省略必要控制。

上述 E30 分解针对每个候选只有一次拟合的情况。多阶段策略中，先拟合 Q、再拟合残差头为两次；
每个交叉拟合子模型、为验证最终重训规则增加的拟合也单独扣减本阶段额度。端到端联合优化一次只计一次。
复用 Q 必须同折 fit、种子、数据/源码/统计/选择身份全部相同，复用不增独立样本数。
所有子模型各有 run_id 与父策略 ID；不允许把任意多个子拟合包装成“一次运行”。
因此使用残差/交叉拟合时，六候选和双确认可能无法同时跑满，需在阶段开始前缩减名单以保留必要控制。

E60 的策略在新 outer 结果产生前冻结，必须包含 F*、P* 与路线 A 最强无卫星赢家，剩余名额再放强 MLP
或一种额外无卫星候选。若 F* 需要额外 Q，Q 占四次拟合之一；多阶段 P* 也按实际拟合计数。
身份重叠时只拟合一次；预算不足以包含必要控制时停止并重新登记，不删掉更强对照凑数。
Persistence/Smart Persistence 必报，Climatology 可在训练区拟合，均不需神经训练。
B* 从这些冻结无卫星策略按三折规则选择；不能在看到 outer 后继续增加架构/调参。
若开发门失败，可结束并发布负结果；E70 不承担继续搜索职责。

## 4. 各组实验的具体设计

### E00–E02：先排除错误，再计价

E00 必查：源 revision、单位/通道、时间与位置、三类样本 hash、训练与评分代码、统计帧数/抽样方式、
空间 jitter、模型参数、CPU/GPU 环境、best/latest/history 的轮次一致性。
仅使用已保存的 validation 预测；从现有 best/latest 补诊断时使用同身份代码/权重，不把新代码输出混回旧目录。

E01 小样本诊断要让无卫星和卫星模型使用相同固定训练键；另用合成可学习目标排除网络/优化错误。
定义新日志 `train_eval_daylight_primary_mae`：固定训练诊断集、关闭增强、eval 模式、同主指标。
同时保存每时效/昼夜损失、梯度/参数更新范数、有效目标数、学习率、墙钟及实际更新步数。
若旧产物没有逐轮权重，只画原有两条明确命名的曲线，不能伪造新增曲线。

E02 先用合成/小样本 FP32 比较 CPU/CUDA 输出、梯度和一步更新，再验证 AMP 有限值、有效目标加权累积
及连续训练与 epoch 边界恢复。FP32 初始目标为归一化输出/损失 `atol=1e-5, rtol=1e-4`，
梯度/更新比较先用相同容差并记录极小值；未通过先定位，不能为使测试通过事后放宽。
AMP 在固定诊断集上的主 MAE 与 FP32 相差不超过 1e-4 归一化单位作为初始工程门，
并检查所有有效预测、损失和梯度有限；这不是跨设备完整训练精度等价保证。
验证无法在当前设备执行时标为未验收，用已验收 CPU 路径继续，不声称 GPU 不存在。

测量每种代表配置至多前 200 batch 和一个完整 epoch，二者重叠计数；不足 200 batch 时使用整轮。
记录首次冷缓存、稳定热缓存、评估、checkpoint 写入、CPU RSS/峰值 VRAM 和数据加载占比。
预算估计为 `各运行(准备 + epoch上限 × 实测epoch + 全部评估/保存)之和 × 1.2`，
准备/epoch 内已计的项目不得再重复相加。若放大图像或变结构，重测该配置后再进矩阵。

### E10：单独检验优化预算

从相同初始化规则重新开始，不续接 old compact checkpoint。数据、损失、增强、归一化、分辨率、
各模型优化器、sampler 与 RNG 规则保持原设定，仅增加最大轮数和早停窗口。MLP 原来随机 shuffle，
融合模型使用 ChunkBucketSampler，不在 E10 统一跨架构采样器。保存实际键序列并核对 power_solar/full
配对序列；相同 seed 不表示全部权重和随机操作相同。独立分支 RNG 或统一采样器若后续引入，另登记为控制变化。

解释规则：同口径 train-eval 与 validation 都持续下降且最好轮次接近上限，支持继续研究训练预算；
train-eval 下降但 validation 长期恶化，支持正则化/数据不足方向；两者都高且梯度弱/异常，先查优化与输入。
三种子不一致写“证据不足”。E10 改善也只能说明新训练条件更好，不证明所有收益来自卫星。

### E20：给卫星一个足够强的参照

默认三类为强 MLP、配对 power_solar、梯度提升树；树或 TCN 二选一，不能都增加为第四类。
MLP/power_solar 各最多四个配置：基准；仅 lr=0.0003；仅 weight_decay=0.0001；仅 dropout=0.2。
每项相对基准只改一个变量。先查现有实现是否支持并将优化器、损失、增强全部显式登记。
树模型若启用，先确定实现/版本，再冻结最多四个深度/叶节点/正则配置；没有冻结数值不能启动筛选。
树的早停看 inner 主指标，使用训练区拟合统计；若所选库无法直接使用该多时效指标，先实现统一回调/包装，
不得偷换成单输出训练损失选最优迭代。六个独立时效模型分别计拟合，需减少配置以遵守运行数上限。
确定性配置只拟合一次，不把复制结果伪装成三个独立种子。

参考特征只用历史功率、可知的未来太阳位置、静态站点信息与缺失标志。增加功率历史长度/趋势/晴空指数
需作为明确候选，匹配卫星模型也使用相同历史；不能用目标构造特征。暂不启用每站点特化模型，
以免四个开发留出站点身份被误当可迁移特征。候选同分按参数/复杂度更低、配置 ID 字典序决定。

### E30：每个改动都有对应反证

从下面候选库按诊断结果预选至多六项，运行前固定顺序、配置与父对照。默认不作全组合网格搜索。
除非登记为新的组合候选，各项都从同一冻结父模型出发；将几个单因素赢家相加也算新的候选，须占一个名额。

| 候选 | 唯一主要变化 | 必需控制与通过含义 |
|---|---|---|
| C01 增强 | jitter 4→0 | 保持一切其他条件；排除相对站点位置被增强扰乱 |
| C02 分辨率 | 32²→64²，视野不变 | 同空间范围/通道；128²替代64²需预登记，不额外偷偷跑第三档 |
| C03 保留位置 | 全局 1×1 池化→固定 2×2 网格或显式中心区域，二选一 | 对照参数量；此项占一个结构名额，不能同时加新时间模块 |
| C04 残差融合 | 使用冻结强功率主干、零初始化卫星残差 | 匹配功率残差头和独立强基线；训练主干/门控规则相同，冻结收益不归给卫星 |
| C05 损失 | 原损失→0.8×日间三时效等权MAE + 0.2×原六时效全部有效目标MAE | power-only 同损失重训；六输出均保留非零监督，报告全部时效/全天副指标 |
| C06 标准化 | 512 个站点帧键→训练期唯一时刻/tile 分层样本 | 固定样本数或明确仅改抽样；增加样本数是另一因素，不能混在一起 |
| C07 动态信息 | 独立训练重复最新帧模型，或显式帧差/光流统计，择一 | 对照最后帧与四帧；只置乱历史属于 E50，不代替重训 |
| C08 时空结构 | 轻量 3D CNN 或 ConvGRU，择一替代 C03/C04 | 固定数据、参数预算和输入；占结构名额，必须有 E00/E50 动态信息证据 |
| C09 通道/物理 | VIS-only 或 IR-only，或一个明确云/晴空特征，择一 | 通道 mask、日夜范围和单位一致；不可同时升级数据源和结构 |
| C10 稳健训练 | 加一个固定比例的模态 dropout 或训练延迟情景，择一 | 与不重训压力结果分开；相同全量服务总体评价与功率回退 |

C05 归约以完整有效 batch（含梯度累积的全部微批）为单位：日间 30/60/120 分钟各自累计误差和有效数，
对有支持的时效求 MAE 后等权平均；某时效本 batch 无支持时不参与这个训练均值。
整个 batch 无日间目标时跳过日间项，仅保留 `0.2 × 原六时效损失`，不临时改成权重 1；
全部目标无效时跳过更新并记录。全天项仍使用自身有效目标分母，不能套用现有单一总分母处理所有项。
新增手算与累积一致性测试覆盖不同微批计数、缺一个时效、纯夜间 batch 和末组；正式评分任一主时效
无支持仍判不可排名，不能用训练的缺项规则绕过评分要求。

纯功率容量对照用于最终候选：尽量匹配参数数量，目标相差≤10%，同时披露 FLOPs/更新数差异；
无法精确匹配时报告限制，不把参数相近当完全相同优化难度。
冻结主干的残差目标只能从 fit 目标构造；如果用另一模型的预测训练门控/堆叠，优先使用训练区间内
按时间交叉拟合得到的预测。禁止用 validation 或 test 的实际误差训练路由器，禁止把未来误差输入模型。

任何正确性问题均使候选不得参与排名或确认；修复后建立新身份，按原预登记规则重新评估。
合格候选按 seed42 主 MAE 排名，最多前两项补三种子。
不能只凭 seed42 宣称有效；确认后按三种子均值选一个 F*，同时应用总方案的改善门。
如果两个结构候选均未改善或确认结果退化，停止本轮结构搜索；新的机制需新版本登记，不能无限加名额。

路线 A 结束时，从所有已登记、同评分总体且完成公平确认的无卫星策略重新确定 B*，包括 E30 新增的
匹配残差、损失对齐和容量对照，不局限于 E20 赢家。未完成必要种子/配对的强候选只能标记待确认；
没有预算补齐时不能忽略它而宣称卫星胜出。E60 必须携带这个最新无卫星赢家；Q 架构仍按 E30 冻结。

### E40–E50：把局部收益与可靠性分开

学习曲线使用训练区间内按完整 UTC 日期选取的 25%/50%/100% 嵌套子集，固定开发验证不变，
两模型使用同一日期键与 mask。对子集保持完整输入/目标范围，不随机拆滑窗。记录日期、站点、独立
天气过程和训练步数；数据量改变也可能改变天气组成，不能把所有改善归因于数量。
路线 B 若重复该试验需另外登记，不能沿用 E40 的六次额度隐性扩张。

E50 在固定 F*、B*、P* 上评估，总方案定义的所有压力情景均固定随机种子和缺失映射。
每组输出实际预测键、失败数、有效目标数、日期/站点数、主 MAE、分时效、回退次数、帧龄。
新延迟输入契约必须先接入 loader，不能通过对齐未来可见图像来模拟“延迟为零”。
极端/云量分组阈值由 fit 数据或输入物理规则固定；基于未来实际波动的分析明确标记事后诊断。

### E60–E70：一次冻结的确认链路

E60 开始前登记全部 fit/inner/outer 的 UTC 起止与站点名单、外部数据 revision、统计抽样、最大预算、
可用性场景、三个 seeds、最多四个学习策略及所有后处理。每个折边界执行完整窗口和物理观测引用检查。
三个非重叠 outer-development 折只是开发证据；不会因为增加折数而成为盲测。

候选配置在 E60 outer 前冻结；inner 只选择各次 checkpoint。B* 按无卫星策略三种子、三折平均主指标选定。
不把逐折最好模型拼成一个未登记“超级基线”，也不让卫星用已知未来天气挑分支。

E70 冻结 F*、P*、B*、内部 Q 和种子；如果 B* 是解析基线，省去其训练。神经模型默认最终训练轮数
为该拟合阶段 E60 inner 最佳 epoch 的中位数向上取整；树模型取其 inner 最佳 boosting 迭代数的中位数
向上取整，确定性统计策略按冻结 fit 规则重算。每个子模型分别登记规则、复用身份与实际拟合数，
使用完整开发训练范围及重新拟合的训练统计，不使用最终 test 早停。
与这些重训规则相关的差异须在 E60 内以开发数据核验，新增拟合也占 E60 额度，
不能把 full 的某个最佳 seed 或某个最佳折权重直接选作唯一最终模型。

最终两个测试分区同次输出、分开报告，解释仅限覆盖日期/地理组。4–8 周终测不能支持全年独立验证；
若需要全年声明，另预登记多季独立窗口。结果不足时可以结束，不必再次搜索以追求≥5%。

## 6. 硬停止与决策分支

1. 数据来源、时间可用性、标签、mask 或源码身份不能解释：停止正式比较，先修复。
2. 有效目标非有限、预测非有限、目标进入特征、分区交叉：运行失败，保留证据，不能过滤后继续排名。
3. 同口径曲线显示过拟合：进入正则化/数据方案，不单方面增加 full 训练轮数。
4. 预算耗尽或所有候选没有改善：停止本轮，交付纯功率主线、卫星负结果及适用范围。
5. 旧数据出现稳健改善：进入有条件新数据确认；没有新数据则只称开发改善。
6. 新时间通过、区域不通过：仅声明已知区域未来时间收益；不能合并均值隐藏迁移失败。
7. 最终测试查看后有实质修复/调参：保存原报告并说明暴露情况，新结论需要新的未见测试。
