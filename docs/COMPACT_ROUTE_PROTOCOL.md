# 精简开发路线：c2w-eval-v2.1

日期：2026-09-28。用户已授权按“明确目标 → 修正现有数据 → 公平对照 → 演示”推进。
本文件在本轮训练结果产生前冻结。暂停原 S3 跨季节/区域扩容路线。

## 目标与数据

预测目标明确为 mean(12 × 三个五分钟 generation_Wh 读数)/(kWp×1000)，称为
“三个采样功率的均值代理”，不称真实电表积分或连续区间平均。数值不变，物理含义改正。
标签契约 c2w-sampled-power-v1；评估协议升为 c2w-eval-v2.1。旧 V2.0 产物不混排或续训。

仅保留原 20 站点、原 30 天和原样本目标 mask。新版本 paired-30d-corrected-v2
使用 sweep=y 从同一卫星源直接写共享 tile，不保存逐站点中间副本。保留旧数据，不扩站点或月份。
新的裁剪必须全部有限，否则停止并重做 QC；不能直接继承旧有效 mask。

所有结论仅为历史冬季开发验证，旧 test 不重新评分，不声称最终独立测试。
卫星采用理想化归档可用时间；不声称在线实时能力。

## 固定比较与计算预算

- Persistence、Smart Persistence：相同 validation 样本、标签、mask 和日间评分。
- 强纯功率候选：PowerMLP，hidden 64。
- 配对纯功率对照：power_solar，embedding 32。
- 卫星候选：full，CNN width 8、embedding 32；对 128² 影像做固定 4×4 平均得到 32²。
- 三个学习候选均跑 seeds 42/123/2026；全部有效训练样本，不用 smoke 上限。
- 每次最多 8 epochs、patience 3、batch 128、lr 0.001、weight decay 0。不根据本轮排名调参。
- 两个融合候选同优化器 AdamW；独立 MLP 沿用 Adam。零 weight decay 下更新形式可比；
  同样的 epoch 预算不代表完全相同耗时、参数量或采样顺序，结果须报告这些差异。
- 在 CPU 执行，torch threads=2；卫星 2 workers。空间下采样为预算内小模型实验，
  不能据此否定更高分辨率模型的潜力。
- 主评分、早停及选 checkpoint 仍为太阳高度角 >5° 的 30/60/120 分钟 MAE 等权平均。
- 按三种子均值比较，报告标准差与各次最佳 epoch；验证站点留出只作开发诊断。
- 对 full 附带置零和 batch 内打乱诊断；后者可能仍含相似云场，不能当作完全无关图像对照。

“有改善”仅指这个预算、数据和指标下的观测结果。8 epochs 未收敛或种子不一致时明说，
不追加有利于某模型的预算。不将种子标准差包装成跨天气独立置信区间。
