# 新增十四天冻结模型评价结果

日期：2026-10-09。按用户授权完成步骤1（冻结模型对照）和2（分组诊断）；未重训或调参。

## 评价与验收

日期2021-04-21至2021-05-05结束不含，共14天。沿用组内上下文QC和原始支持边界检查，最终38,269条共同样本；主指标30/60/120分钟各有21,703/21,672/21,648个有效日间目标，按时效等权。太阳高度须大于5度。先平均三种子的绝对误差，不是集成预测。

所有18个冻结模型/归一化文件哈希保持不变；9个模型GPU推理后由CPU抽样回放验证通过；样本、目标、掩码、边界与独立指标复算通过。两项统计单元测试通过。无训练、下载、MVP替换或2022最终标签读取。执行约14.2分钟。

## 主指标

误差为装机容量的百分比，越低越好。

| 方法 | 日间30/60/120分钟平均MAE |
|---|---:|
| 晴空修正基线 | 9.384% |
| 功率＋太阳 | 9.162% |
| 原卫星统计 | 8.853% |
| 中心32×32卫星 | 8.576% |

中心32×32相对功率太阳降低0.586个容量百分点，相对降幅6.39%；三个种子均改善，14天中11天日均指标改善。

主比较为中心32×32减功率太阳，负值有利：

- 整UTC日期配对bootstrap，10,000次：95%区间[-1.055, -0.137]容量百分点，不包含零。
- 连续3天循环移动块敏感性分析，10,000次：95%区间[-1.108, 0.005]容量百分点，略跨零。
- 原卫星相对功率太阳的两种区间均跨零。晴空基线比较为次要比较，不做额外显著性宣称。

因此小范围卫星有积极迹象，但结论依赖日期独立性假设，不能宣称跨天气过程稳健显著或全年泛化成立。三个随机种子不是三倍独立验证日期。

## 日照和历史波动（探索性）

| 组别 | 功率＋太阳 | 原卫星 | 中心32×32 | 晴空基线 |

| 太阳高度5–20度 | 3.834% | 3.857% | 3.784% | 4.380% |
| 太阳高度20–40度 | 8.535% | 8.533% | 8.275% | 9.165% |
| 历史功率中波动 | 8.031% | 7.830% | 7.755% | 7.501% |
| 历史功率低波动 | 5.798% | 5.257% | 4.921% | 5.295% |

太阳高度较高时小图块绝对改善更大，低太阳高度时差别很小。低、中、高历史波动组中，小图块都优于功率太阳；没有证据把收益简单归结为只在高波动条件下有效。中波动组晴空基线仍最佳。

波动定义为最近4个功率值的最大相邻变化，阈值仅从旧extended训练集日间样本取三分位：1.817、6.654容量百分点。太阳高度是几何条件，不等于实测晴天/多云；历史功率波动不是未来天气标签。各子组都覆盖14日期，但有效目标数量不同，详见results.json；组间差异可能混杂站点、时效和日期分布，不能解释为因果效应或直接用作部署开关。
