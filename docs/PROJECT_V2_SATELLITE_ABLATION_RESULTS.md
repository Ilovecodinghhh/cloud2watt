# 卫星处理对照验证结果（2026-10-09）

结论：在本轮冻结开发划分中，中心32×32图块的春季合并误差最低；昼夜处理单独作用很小；当前“中位数/IQR＋±5裁剪”方案单独使用反而变差。组合方案在最后春季窗口和相同模型的冬季验证上表现较好，但不能稳定胜过单独小图块。保持现有 MVP 默认策略，不自动部署新模型。

## 实验与验收

依据 ADR 019，四个新处理 × 三个窗口 × 三个种子，共36次指定 Conda RTX 5070 Ti GPU训练，每次20轮。功率、太阳与站点特征保持不变，所有模型输入132维、MLP结构与训练预算相同，全部复用冻结 dataset.npz。没有筛除评价样本、下载数据或读取最终测试标签。

共提取115,632个不同历史帧的中心图块特征，其中27个历史帧位于相邻分区上下文；首次日分区对齐检查中止后补齐读取，未改变模型样本。原105维统计向量按帧统计量与帧差重组，与原向量逐位一致。稳健变体仅卫星特征采用训练集中位数、IQR/1.349和±5截断；功率等仍用训练均值/标准差。昼夜gate为clip(历史帧太阳高度/5,0,1)，只作用于VIS006和IR_016，之后重算帧差。图块中心32×32与原128×128采用相同105维统计格式。

四项单元测试通过。独立验收36个检查点：归一化仅由训练集拟合、检查点仅由内部验证选轮次、新旧预测样本/目标/掩码完全一致、保存的模型和处理参数能够复现预测。成功流程耗时约 9.3 分钟（含特征提取和训练，不含首次对齐修复及独立验收）。

## 总体误差

均为白天30/60/120分钟MAE占装机容量比例，越低越好。三个种子先平均绝对误差，不是预测集成后打分。

| 方法 | 春季滚动12天 | 冬季6天（最后窗口模型） |
|---|---:|---:|
| 晴空修正基线 | 10.69% | 5.03% |
| 功率＋太阳 | 10.52% | 5.07% |
| 原卫星128×128 | 10.27% | 5.16% |
| 仅昼夜处理 | 10.22% | 5.17% |
| 仅稳健缩放＋裁剪 | 10.57% | 5.28% |
| 仅中心32×32 | 10.05% | 4.97% |
| 三者组合 | 10.08% | 4.92% |

春季为4月9–20日三个不重叠外部开发窗口、30,606条样本；冬季列只用 extended 同组模型在1月23–28日的表现，未将同一冬季日期在三个窗口中重复计为独立日期。春季与冬季数字来自不同评价日期，不能直接归因为季节本身。

## 配对统计

以UTC日期为整体重采样，同日站点和对应种子保持配对，10,000次bootstrap。以下为“新处理−原卫星”的MAE差，单位为装机容量百分点，负数代表改善。98.75%区间对应四项比较的Bonferroni调整。

| 新处理 | 差值 | 95%区间 | 98.75%调整区间 |
|---|---:|---|---|
| 三者组合 | -0.196 | [-0.665, 0.309] | [-0.781, 0.448] |
| 仅昼夜处理 | -0.053 | [-0.172, 0.067] | [-0.204, 0.102] |
| 仅中心32×32 | -0.220 | [-0.791, 0.298] | [-0.962, 0.402] |
| 仅稳健缩放＋裁剪 | 0.291 | [0.098, 0.475] | [0.045, 0.526] |

昼夜、小图块、组合的区间均包含零，尚无稳定胜出的统计证据。稳健方案区间位于零以上，支持其在本轮开发数据上变差；这仍不是独立最终测试结论。数据日期已用于开发，天气相邻日期相关、窗口训练集重叠，区间条件于这三个种子；不将每个15分钟样本当独立统计单位。

## 决策

- 优先保留中心32×32作为后续候选方向，但不据本轮均值自动替换默认模型。
- 不采用本轮稳健缩放＋裁剪配方；本试验无法区分缩放和裁剪各自贡献，不能推断所有稳健处理无效。
- 不把三者组合视为默认最佳；单独昼夜处理收益有限。
- 没有按外部误差继续搜索尺寸、gate或裁剪阈值。旧模型、训练产物及最终测试门保持不变。
